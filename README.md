## Open-Source Tour Libraries

- [Bootstrap Tour](https://github.com/sorich87/bootstrap-tour) - Bootstrap Tour is an open-source library for building quick and easy product tours with Bootstrap popovers. It is designed for websites using Bootstrap and can be self-hosted. The project is licensed under MIT. ([Read more](/details/bootstrap-tour.md)) `Open Source` `MIT` `JavaScript` `Bootstrap` `Self-Hosted`
- [Driver.js](https://github.com/kamranahmedse/driver.js) - Driver.js is an open-source JavaScript library for highlighting page elements and creating guided tours. It is lightweight, dependency-free, and suitable for self-hosted web applications. The code is distributed under the MIT license. ([Read more](/details/driver-js.md)) `Open Source` `MIT` `JavaScript` `Self-Hosted`
- [Hopscotch](https://github.com/linkedin/hopscotch) - Hopscotch is an open-source tour library originally developed by LinkedIn for adding guided tours to web pages. It supports multiple tour steps, custom positioning, and event callbacks. The project is available under the MIT license. ([Read more](/details/hopscotch.md)) `Open Source` `MIT` `JavaScript` `Self-Hosted`
- [Intro.js](https://introjs.com/) - Intro.js is an open-source JavaScript library for creating step-by-step introductions and product tours on websites. Developers can self-host and customize the tours using CSS and JavaScript. It is released under the MIT license. ([Read more](/details/intro-js.md)) `Open Source` `MIT` `JavaScript` `Self-Hosted`
- [Shepherd.js](https://shepherdjs.dev/) - Shepherd.js is an open-source library for building product tours using Tether for positioning.
